# RIVAN.ME

Minimalist editorial portfolio of Muhamad Rivan Sahronie. Built with a focus on typography, negative space, and a no-scroll interface.

[View Live Site](https://rivan.me)

---

### tech stack
- **core**: react + vite
- **styling**: tailwind css (v4)
- **i18n**: i18next (en/id support)
- **icons**: lucide react
- **font**: plus jakarta sans

### features
- **editorial layout**: a magazine-style fixed interface.
- **no-scroll navigation**: purely pagination-based content browsing.
- **bilingual**: seamless switching between english and indonesian.
- **dual-cv**: dynamic cv downloads based on active language.

### development
```bash
# install dependencies
pnpm install

# start development server
pnpm run dev

# build for production
pnpm run build
```
